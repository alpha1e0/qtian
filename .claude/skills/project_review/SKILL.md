## 🕵️ Review & Nitpick Skill
这个技能专门用于对代码、文档或方案进行深度review，“全方位挑刺”，寻找潜在风险、逻辑漏洞和不规范之处。

### 触发条件

- 关键词：`review`, `critique`, `挑刺`, `审查`

### 审查清单（挑刺指南）

1. **安全性 (Security)**：
	a. 是否存在注入风险、敏感信息泄露或鉴权漏洞
	b. 日志输出的内容是否有敏感内容
	b. 代码、文档中是否存在api_key等敏感信息，是否包含政治、色情等违规信息
2. **边界情况 (Edge Cases)**：输入为空、极大值、非法字符等情况是否处理
3. **可维护性 (Maintainability)**：变量命名是否具有迷惑性，函数是否过长
4. **性能/效率 (Efficiency)**：是否存在不必要的循环、重复的 API 调用、为用到的函数、类、文件
5. **一致性 (Consistency)**：需求设计文档和代码是否一致
6. **测试(Testing)**: 单元测试和e2e测试是否覆盖
7. **命名规范**：文件、目录、类、函数、变量命令是否合理
8. **注释**: 是否包含必要的注释
