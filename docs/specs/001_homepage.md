# 工具首页 需求设计

## 1. 概述 (Overview)

工具首页提供一个简洁的对话输入入口，用户输入消息后自动创建对话并跳转到 AI 助手页面。

## 2. UI设计

**界面居中展示**，仅包含一个对话输入区域：

1. `对话输入框`。使用 textarea 组件，居中显示，支持多行输入
2. `发送按钮`。位于输入框下方或右侧

**交互逻辑**：
- 用户在输入框中输入消息
- 点击发送按钮或按 `Ctrl+Enter` 触发发送
- 发送后自动跳转到 AI 助手页面，并携带用户输入的消息
- AI 助手页面自动创建新对话（以消息内容为标题）并发送该消息

**注意**：保持渐变背景和居中布局风格
